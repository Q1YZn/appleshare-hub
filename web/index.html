iOS 26 登录 / 退出教程

媒体与购买项目入口已统一到设置，共享账号只允许在 App Store 使用。

  1. 退出旧账号 打开 App Store，点击右上角头像图标，滑动页面到底部，选择“退出登录”以登出当前账号。
  2. 登录共享账号 输入平台提供的 Apple ID 和密码登录。如遇 Apple ID 安全提示，点击“其他选项”并选择“不升级”，跳过双重认证。
  3. 下载应用 登录后搜索需要的 App，例如 Shadowrocket。显示付费提示请无视并继续，部分账号已支持下载。
  4. 配置使用 应用安装完成后返回软件内部配置或导入节点信息。
  5. iOS 26 退出 进入 设置 > 你的姓名 / Apple 账户 > 媒体与购买项目 > 退出登录，完成后不要再用该账号登录 iCloud。

详细文字与图片教程参考 idfree.top； Apple 官方示意图来自 Apple 支持文档。
