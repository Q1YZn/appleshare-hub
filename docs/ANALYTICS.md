# 访问统计

项目内置一个轻量埋点，用于按天统计去重用户数（UV）。

## 统计逻辑

- 前端为每个浏览器生成匿名 `uid`，保存在 `localStorage`。
- 同一个浏览器在自然日内只上报一次，避免刷新页面重复计数。
- 后端按 `Asia/Shanghai` 时区写入 R2，Key 为 `stats/daily/YYYY-MM-DD.json`。
- 数据结构：`{ "date": "2026-08-12", "uv": 1, "uids": ["..."] }`。
- 统计接口只返回日期和 `uv`，不会公开完整 `uids`。

## API

### `POST /api/track`

埋点上报接口，由前端自动调用。

```json
{
  "uid": "anonymous-user-id"
}
```

### `GET /api/stats?days=7`

查询最近 N 天的统计，默认 7 天，最大 90 天。

```json
{
  "code": 200,
  "days": 7,
  "rows": [
    { "date": "2026-08-12", "uv": 1 }
  ]
}
```

## 说明

- 统计是匿名近似值：清除浏览器数据或更换设备会生成新的 `uid`。
- 统计只记录用户量，不记录页面浏览次数（PV）。
- 数据保留在 R2 的 `stats/` 前缀下，不会和账号快照混在一起。
